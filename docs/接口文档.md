# B2C 商城后端 · 接口文档

> 版本 v1.0.0　　Base URL：`http://127.0.0.1:8000/api/v1`（公网部署后替换为 `http://<公网IP>:<端口>/api/v1`）
>
> 交互式调试：服务启动后打开 `/docs`（Swagger UI）。机器可读规范：[docs/openapi.json](./openapi.json)。
> 设计口径与错误码含义见 [功能设计文档](./功能设计文档.md) 第四章。

## 阅读须知

1. **统一响应体**：所有接口都返回下面三层结构，业务数据只在 `data` 里。

   ```json
   { "code": 0, "message": "success", "data": {} }
   ```

   `code = 0` 即成功；非 0 时 HTTP 状态码同步变为 4xx/5xx，`data` 为 `null`。
2. **鉴权**：除标注「公开」的接口外，都要带请求头 `Authorization: Bearer <access_token>`。
   令牌由「登录」接口返回，默认有效期 120 分钟。
3. **示例中的域名**统一写 `http://127.0.0.1:8000`，请自行替换。
4. **金额一律以字符串返回**（如 `"3999.00"`），固定两位小数。数据库用 `DECIMAL` 存储，
   序列化走字符串是为了避开 JavaScript `number` 的浮点精度问题；前端展示时直接拼接，
   参与计算时请先转成定点数。
5. 下文所有响应示例均为**真实调用结果**（由 `python -m scripts.smoke_test` 跑通后整理）。

## 一、用户与登录

### 1.1 注册新用户

`POST /api/v1/auth/register`　公开

| 字段 | 类型 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- | --- |
| `username` | string | 是 | 4–32 位，仅字母和数字 | 登录名，全局唯一 |
| `password` | string | 是 | 6–64 位 | 登录密码，服务端存 bcrypt 散列 |
| `nickname` | string | 否 | ≤32 位 | 昵称，留空时取登录名 |
| `phone` | string | 否 | ≤20 位纯数字 | 手机号 |
| `email` | string | 否 | ≤128 位 | 邮箱 |

```bash
curl -X POST http://127.0.0.1:8000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan01","password":"Test@123456","nickname":"张三","phone":"13900000001"}'
```

响应 `201 Created`：

```json
{
  "code": 0,
  "message": "注册成功",
  "data": {
    "id": 3,
    "username": "zhangsan01",
    "nickname": "张三",
    "phone": "13900000001",
    "email": null,
    "avatar": "",
    "role": "user",
    "status": 1,
    "created_at": "2026-11-03T15:41:07"
  }
}
```

失败示例（登录名重复）`409 Conflict`：

```json
{ "code": 40900, "message": "登录名 zhangsan01 已被注册", "data": null }
```

### 1.2 登录换取访问令牌

`POST /api/v1/auth/login`　公开

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `username` | string | 是 | 登录名 |
| `password` | string | 是 | 登录密码 |

```bash
curl -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan01","password":"Test@123456"}'
```

响应 `200 OK`：

```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIzIiwicm9sZSI6InVzZXIiLCJpYXQiOjE3NjMwNTIwNjcsImV4cCI6MTc2MzA1OTI2N30...",
    "token_type": "bearer",
    "expires_in": 7200,
    "user": {
      "id": 3,
      "username": "zhangsan01",
      "nickname": "张三",
      "phone": "13900000001",
      "email": null,
      "avatar": "",
      "role": "user",
      "status": 1,
      "created_at": "2026-11-03T15:41:07"
    }
  }
}
```

密码错误 `401 Unauthorized`：

```json
{ "code": 40100, "message": "登录名或密码错误", "data": null }
```

> Swagger UI 里点右上角 **Authorize**，把 `access_token` 粘进去，后续接口即可直接试。

### 1.3 查看当前登录用户

`GET /api/v1/auth/me`　需登录

```bash
curl http://127.0.0.1:8000/api/v1/auth/me -H "Authorization: Bearer <token>"
```

响应 `200 OK`：`data` 结构同 1.1 的响应。

### 1.4 修改个人资料

`PUT /api/v1/auth/me`　需登录

只传需要改的字段，未传字段保持不变；**不能**通过本接口改密码或角色。

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `nickname` | string | ≤32 位 |
| `phone` | string | ≤20 位 |
| `email` | string | ≤128 位 |
| `avatar` | string | ≤255 位 |

```bash
curl -X PUT http://127.0.0.1:8000/api/v1/auth/me \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"nickname":"张三丰","email":"zsf@example.com"}'
```

## 二、商品类别

### 2.1 分类树（一级带二级）

`GET /api/v1/categories/tree`　公开

| 查询参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `include_hidden` | bool | `false` | 传 `true` 时包含隐藏分类，供管理员预览 |

```bash
curl "http://127.0.0.1:8000/api/v1/categories/tree"
```

响应 `200 OK`（节选）：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "name": "手机数码",
      "parent_id": null,
      "level": 1,
      "icon": "/static/cat/digital.png",
      "sort_order": 1,
      "status": 1,
      "children": [
        { "id": 11, "name": "智能手机", "parent_id": 1, "level": 2,
          "icon": "", "sort_order": 1, "status": 1 },
        { "id": 12, "name": "笔记本电脑", "parent_id": 1, "level": 2,
          "icon": "", "sort_order": 2, "status": 1 }
      ]
    }
  ]
}
```

### 2.2 分类平铺列表

`GET /api/v1/categories`　公开　参数同 2.1。响应 `data` 为不带 `children` 的一维数组。

### 2.3 分类详情

`GET /api/v1/categories/{category_id}`　公开

不存在时返回 `404`：`{"code":40400,"message":"分类 999 不存在","data":null}`

### 2.4 新建分类

`POST /api/v1/categories`　**管理员**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | string | 是 | 1–50 位 |
| `parent_id` | int | 否 | 不传即一级分类；最多两级 |
| `icon` | string | 否 | 图标地址 |
| `sort_order` | int | 否 | ≥0，越小越靠前 |
| `status` | int | 否 | 1 显示 / 0 隐藏 |

```bash
curl -X POST http://127.0.0.1:8000/api/v1/categories \
  -H "Authorization: Bearer <admin_token>" -H "Content-Type: application/json" \
  -d '{"name":"平板","parent_id":1,"sort_order":4}'
```

响应 `201 Created`，`data` 为新分类对象。

失败：普通用户调用 → `403 {"code":40300,"message":"该操作仅管理员可用"}`；
在二级分类下再建子级 → `409 {"code":40900,"message":"最多支持两级分类"}`；
同级重名 → `409 {"code":40900,"message":"同级下已存在分类「平板」"}`。

### 2.5 修改分类

`PUT /api/v1/categories/{category_id}`　**管理员**　字段均可选，只传要改的。

### 2.6 删除分类

`DELETE /api/v1/categories/{category_id}`　**管理员**

有子分类或有商品时拒绝删除：

```json
{ "code": 40900, "message": "该分类下还有 3 个商品，无法删除", "data": null }
```

## 三、商品

### 3.1 商品列表

`GET /api/v1/products`　公开

| 查询参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | — | 按商品名/副标题模糊搜索，≤50 位 |
| `category_id` | int | — | 分类 ID；传一级分类会级联其下所有二级分类 |
| `min_price` | decimal | — | 价格下限（含） |
| `max_price` | decimal | — | 价格上限（含） |
| `sort` | string | `default` | `default` / `price_asc` / `price_desc` / `sales_desc` / `newest` |
| `page` | int | 1 | ≥1 |
| `page_size` | int | 10 | 1–100 |
| `show_all` | bool | false | 管理员传 `true` 可看到已下架商品 |

```bash
curl "http://127.0.0.1:8000/api/v1/products?category_id=1&sort=price_asc&page=1&page_size=2"
```

响应 `200 OK`：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 104, "category_id": 13, "name": "潮汐 Watch 运动手表",
        "subtitle": "智能穿戴·热销款", "main_image": "/static/goods/0004.jpg",
        "price": "899.00", "original_price": "1099.00", "stock": 200, "sales": 40,
        "unit": "只", "status": 1, "category_name": "智能穿戴"
      }
    ],
    "total": 4, "page": 1, "page_size": 2, "pages": 2
  }
}
```

### 3.2 商品详情

`GET /api/v1/products/{product_id}`　公开

响应比列表多一个 `detail`（图文详情）字段。

### 3.3 发布商品

`POST /api/v1/products`　**管理员**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `category_id` | int | 是 | 必须已存在 |
| `name` | string | 是 | 1–120 位，不可与已有商品重名 |
| `price` | decimal | 是 | ≥0.01 |
| `original_price` | decimal | 否 | 划线价 |
| `stock` | int | 否 | ≥0 |
| `subtitle` / `main_image` / `unit` / `detail` | string | 否 | — |
| `status` | int | 否 | 1 在售 / 0 下架 |

```bash
curl -X POST http://127.0.0.1:8000/api/v1/products \
  -H "Authorization: Bearer <admin_token>" -H "Content-Type: application/json" \
  -d '{"category_id":11,"name":"星海 13 标准版","price":"2999.00","stock":80,"unit":"台"}'
```

响应 `201 Created`。分类不存在 → `404`；重名 → `409`。

### 3.4 修改商品

`PUT /api/v1/products/{product_id}`　**管理员**　字段均可选。

### 3.5 下架商品

`DELETE /api/v1/products/{product_id}`　**管理员**

下架只把 `status` 置 0，记录仍在库里，历史订单不受影响。下架后公开列表查不到该商品。

## 四、购物车

### 4.1 查看购物车

`GET /api/v1/cart`　需登录

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1, "product_id": 101, "product_name": "星海 12 Pro 5G 手机",
        "product_image": "/static/goods/0001.jpg", "price": "3999.00",
        "quantity": 2, "checked": 1, "subtotal": "7998.00",
        "stock": 120, "on_sale": true
      }
    ],
    "total_quantity": 2,
    "total_amount": "7998.00",
    "checked_count": 1
  }
}
```

`total_quantity` / `total_amount` 只统计 `checked = 1` 的行。

### 4.2 加入购物车

`POST /api/v1/cart`　需登录

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `product_id` | int | 是 | 商品 ID |
| `quantity` | int | 否 | 1–999，默认 1 |

同一商品重复加购会**累加**数量并把该行置为勾选。商品不存在 → `404`；已下架 → `409`；
累加后超过库存 → `400 {"code":40000,"message":"库存不足，当前仅剩 30 台"}`。

响应 `201 Created`，`data` 为加购后的完整购物车（结构同 4.1）。

### 4.3 修改数量或勾选状态

`PUT /api/v1/cart/{item_id}`　需登录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `quantity` | int | 1–999，改完仍会校验库存 |
| `checked` | int | 1 勾选 / 0 取消勾选 |

响应 `200 OK`，`data` 为更新后的完整购物车。

### 4.4 移除一件

`DELETE /api/v1/cart/{item_id}`　需登录　响应为剩余购物车。

### 4.5 清空购物车

`DELETE /api/v1/cart`　需登录

```json
{ "code": 0, "message": "购物车已清空",
  "data": { "items": [], "total_quantity": 0, "total_amount": "0.00", "checked_count": 0 } }
```

> 只能操作自己的购物车行，改别人的 `item_id` 返回 `404`（不暴露他人数据是否存在）。

## 五、订单

### 5.1 提交订单

`POST /api/v1/orders`　需登录

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `receiver_name` | string | 是 | 2–32 位 |
| `receiver_phone` | string | 是 | 6–20 位 |
| `receiver_address` | string | 是 | 5–255 位 |
| `remark` | string | 否 | ≤255 位 |
| `items` | array | 否 | **直接购买**清单，元素为 `{product_id, quantity}`；不传则结算购物车中已勾选的商品 |

```bash
curl -X POST http://127.0.0.1:8000/api/v1/orders \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"receiver_name":"张三","receiver_phone":"13900000001",
       "receiver_address":"北京市海淀区中关村大街1号","remark":"工作日送达"}'
```

响应 `201 Created`：

```json
{
  "code": 0,
  "message": "下单成功，请在有效期内付款",
  "data": {
    "id": 1,
    "order_no": "202611031444077809954",
    "status": 0,
    "status_label": "待付款",
    "total_amount": "7998.00",
    "freight": "0.00",
    "pay_amount": "7998.00",
    "receiver_name": "张三",
    "receiver_phone": "13900000001",
    "receiver_address": "北京市海淀区中关村大街1号",
    "remark": "工作日送达",
    "item_count": 1,
    "total_quantity": 2,
    "created_at": "2026-11-03T14:44:07",
    "paid_at": null,
    "items": [
      { "id": 1, "product_id": 101, "product_name": "星海 12 Pro 5G 手机",
        "product_image": "/static/goods/0001.jpg", "price": "3999.00",
        "quantity": 2, "subtotal": "7998.00" }
    ],
    "shipped_at": null, "finished_at": null, "cancelled_at": null
  }
}
```

下单副作用：**库存立即扣减**、**已结算的购物车行被删除**、明细写入商品名称与价格快照。
运费规则：商品总额满 99 元免运费，否则 10 元。

失败示例：

```json
{ "code": 400, "message": "购物车里没有勾选任何商品", "data": null }
{ "code": 40000, "message": "商品「云感 降噪耳机」库存不足，仅剩 0 副", "data": null }
```

### 5.2 我的订单列表

`GET /api/v1/orders`　需登录

| 查询参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `status` | int | — | 0 待付款 / 1 待发货 / 2 待收货 / 3 已完成 / 4 已取消 |
| `page` | int | 1 | ≥1 |
| `page_size` | int | 10 | 1–50 |

响应 `data.items` 为订单摘要（不含 `items` 明细数组）。

### 5.3 订单详情

`GET /api/v1/orders/{order_id}`　需登录　仅本人可见，管理员可查看全部；他人订单返回 `403`。

### 5.4 支付订单（模拟）

`PUT /api/v1/orders/{order_id}/payment`　需登录（本人）

状态 `0 待付款 → 1 待发货`，写入 `paid_at`，并累加商品销量。
真实支付对接（微信/支付宝回调）本期已裁剪，见功能设计文档 R10。

非待付款状态重复调用：

```json
{ "code": 40000, "message": "当前状态为「待发货」，不能执行该操作", "data": null }
```

### 5.5 发货

`PUT /api/v1/orders/{order_id}/shipment`　**管理员**　`1 待发货 → 2 待收货`，写入 `shipped_at`。

### 5.6 确认收货

`PUT /api/v1/orders/{order_id}/receipt`　需登录（本人）　`2 待收货 → 3 已完成`，写入 `finished_at`。

### 5.7 取消订单

`PUT /api/v1/orders/{order_id}/cancellation`　需登录（本人）

- `0 待付款 → 4 已取消`：回滚库存。
- `1 待发货 → 4 已取消`：回滚库存与销量，退款线下处理。
- `2/3/4` 状态不可取消，返回 `400`。

## 附录：错误响应汇总

| 场景 | HTTP | `code` | `message` 示例 |
| --- | --- | --- | --- |
| 未带令牌访问购物车 | 401 | 40100 | 请先登录 |
| 令牌过期 | 401 | 40100 | 登录已过期，请重新登录 |
| 令牌被篡改 | 401 | 40100 | 登录凭证无效，请重新登录 |
| 账号被禁用 | 401 | 40100 | 账号已被禁用，请联系管理员 |
| 普通用户建分类 | 403 | 40300 | 该操作仅管理员可用 |
| 查他人订单 | 403 | 40300 | 只能操作自己的订单 |
| 用户名含非法字符 | 422 | 40000 | username 校验失败：登录名只能由字母和数字组成 |
| 数量传 0 | 422 | 40000 | items.0.quantity 校验失败：Input should be greater than or equal to 1 |
| 商品不存在 | 404 | 40400 | 商品 99999 不存在 |
| 登录名重复 | 409 | 40900 | 登录名 zhangsan01 已被注册 |
| 库存不足 | 400 | 40000 | 商品「潮汐 Watch 运动手表」库存不足，仅剩 1 只 |
| 状态机不允许 | 400 | 40000 | 当前状态为「已完成」，不能执行该操作 |
